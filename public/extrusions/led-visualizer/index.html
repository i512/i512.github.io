LED Animation Visualizer

Write JavaScript that mutates leds on every interval tick.

Available API
  • leds: array of LED objects: { x, y, z, r, g, b }
  • time: seconds since animation start
  • iteration: current execution count
  • delta: seconds since previous execution
  • clamp(value, min, max) and rgb(r, g, b)
